# 📦 Alaria Link – EP Smart Hub

**Alaria Link** es un sistema modular inteligente enfocado en la gestión operativa de pequeñas y medianas empresas B2C (Business-to-Consumer) y B2B (Business-to-Business). Forma parte del ecosistema **EP Smart Hub**, un conjunto de soluciones empresariales integradas para digitalizar procesos administrativos y logísticos.

---

## 🚀 Módulos Activos en el MVP "Minimum Viable Product"

### 🔖 Módulo de Facturación
- Registro de facturas de venta.
- Generación de consecutivos automáticos.
- Gestión de impuestos, descuentos, y notas crédito.
- Compatible con clientes B2C y B2B.

### 🧾 Módulo de Compras
- Registro de órdenes y facturas de compra.
- Relación directa con proveedores.
- Ingreso automático al inventario.

### 📦 Módulo de Inventarios (Entradas y Salidas)
- Control de movimientos por bodega.
- Ajustes manuales y automáticos.
- Kardex por producto.
- Alertas por stock mínimo.

### 📋 Módulo de Productos
- Registro y edición de productos y servicios.
- Soporte para código de barras y SKU.
- Clasificación ABC y rotación automática.
- Imágenes, categorías y atributos adicionales.

### 🧑‍🤝‍🧑 Módulo de Creadores (Clientes y Proveedores)
- Registro y gestión de terceros.
- Perfiles detallados por tipo.
- Historial de compras/ventas por entidad.

### 💸 Módulo de Egresos
- Registro de pagos y salidas de efectivo.
- Asociación a compras o egresos varios.
- Soporte para múltiples medios de pago.

### 🔍 Módulos de Consultas
- Consulta rápida de movimientos.
- Historial por producto, cliente o proveedor.
- Filtros por fecha, documento o usuario.

### 📊 Módulos de Informes
- Inventario valorizado.
- Productos por rotación (ABC).
- Ventas por período o por cliente.
- Compras por proveedor.
- Egresos y flujo de caja.

---

## ⚙️ Tecnologías utilizadas

- **Frontend:** WPF (según stack final)
- **Backend:** C# (modificable)
- **Base de datos:** MySQL
- **API REST:** Modular y documentada
- **Autenticación:** JWT (o sistema basado en sesiones)
- **Otros:** Docker (opcional), Swagger (para documentación API)
